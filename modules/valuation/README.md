Strata-Valuation
-----------
This directory contains the `strata-valuation` module.

### Overview

This module provides the classes used by Strata when performing valuation functions.
It aims to make it easy to calculate measures, such as present value,
on a list of targets, typically trades, using JSON representations.
To achieve this, the system manages market data, such as quotes, curves and surfaces,
and provides a simple interface for valuation.

The interface, `ValuationFunction` provides the main API.
